# 🎙️ AI 영어회화 프로그램

PC(브라우저)에서 동작하는 음성 영어회화 연습 프로그램입니다.
마이크로 영어를 말하면 AI(Claude)가 알아듣고, 자연스럽게 대답하고 소리 내어 읽어주며, 문법·표현을 부드럽게 교정해줍니다.

## 구성

- **음성 인식(STT)**: 브라우저 내장 Web Speech API (Chrome / Edge 권장, 무료)
- **음성 출력(TTS)**: 브라우저 내장 SpeechSynthesis (무료)
- **대화 두뇌**: Claude API (로컬 서버가 API 키를 안전하게 보관하고 호출)
- **서버**: Node.js + Express (작은 프록시 서버)

## 실행 방법 (처음 한 번만 설정)

### 1. API 키 준비

1. https://console.anthropic.com 에 로그인 → **API Keys** 에서 키 발급 (`sk-ant-...`)
2. 이 폴더의 `.env.example` 파일을 복사해서 이름을 **`.env`** 로 바꿉니다.
3. `.env` 파일을 열어 발급받은 키를 넣습니다:
   ```
   ANTHROPIC_API_KEY=sk-ant-실제키붙여넣기
   ```

> 💡 API 키는 사용한 만큼 요금이 부과됩니다. 회화 연습은 요청당 비용이 매우 작지만, 키는 외부에 노출되지 않도록 `.env` 파일에만 보관하세요. (`.gitignore`에 이미 제외돼 있습니다.)

### 2. 패키지 설치 (터미널에서)

이 폴더에서 PowerShell 을 열고:

```powershell
npm install
```

### 3. 실행

```powershell
npm start
```

터미널에 `http://localhost:3000` 주소가 표시되면, **Chrome 또는 Edge** 브라우저에서 그 주소로 접속하세요.

## 여섯 가지 모드 (상단 메뉴에서 전환)

- **🎙️ 회화** (`/`) — 음성으로 자유 대화 연습
- **👂 쉐도잉** (`/shadowing.html`) — 리스닝 받아쓰기 연습
- **🎧 듣기** (`/listen.html`) — 쉐도잉한 문장들을 모아 무한 반복으로 흘려듣기
- **📖 읽기** (`/reading.html`) — A4 1페이지 분량 지문 읽기 + 드래그 해석
- **✍️ 쓰기** (`/writing.html`) — 한국어 문장을 영어로 옮겨 쓰기 (영작)
- **🗣️ 말하기** (`/speaking.html`) — 한국어 문장을 영어로 말하기 (스피킹)

## 사용법 — 🎙️ 회화

- **🎤 말하기** 버튼을 누르고 영어로 말하면 AI가 알아듣고 대답합니다. (첫 사용 시 마이크 권한 허용 필요)
- AI의 답변은 자동으로 소리 내어 읽어줍니다. **🔊 다시 듣기** 로 다시 들을 수 있습니다.
- 문법/표현 실수가 있으면 답변 아래에 **✍️ 교정**이 초록색으로 표시됩니다.
- 마이크 대신 아래 입력창에 **텍스트로 입력**할 수도 있습니다.
- 우측 상단에서 **음성(발음)** 과 **속도** 를 조절할 수 있습니다.
- **🔇** 버튼으로 읽기를 멈출 수 있습니다.

## 사용법 — 👂 쉐도잉 (리스닝 받아쓰기)

1. **🔄 새 문장** 버튼을 누르면 중급 수준의 10~15단어 영어 문장이 하나 만들어지고 자동으로 재생됩니다. (정답은 제출 전까지 숨겨집니다.)
2. **▶️ 문장 듣기** 로 원하는 만큼 반복해서 들을 수 있습니다.
3. 들은 문장을 입력창에 타이핑하고 **제출하고 채점** 을 누르면:
   - 맞은 단어는 **초록색**, 놓친 단어는 **노란색**, 틀리거나 불필요한 단어는 **빨간 취소선**으로 표시됩니다.
   - 정확도(%)와 정답 문장을 함께 보여줍니다.
4. **🔄 새 문장** 으로 계속 이어서 연습하세요.

> 쉐도잉에서 만든 문장은 **자동으로 저장**되어 🎧 듣기 모드에서 다시 들을 수 있습니다.

## 사용법 — 🎧 듣기 (흘려듣기)

일을 하면서 배경으로 틀어놓고 반복 청취하는 모드입니다.

- 쉐도잉에서 연습한 문장이 **자동으로 목록에 쌓입니다.** (브라우저에 저장 — localStorage)
- **▶️ 전체 반복 재생** 을 누르면 저장된 문장을 순서대로 무한 반복 재생합니다.
- 옵션:
  - **문장 사이** 간격 (0.5 ~ 3초)
  - **🇰🇷 번역도 읽기** — 각 문장 뒤에 한글 번역을 읽어줍니다 (시스템에 한국어 음성이 있을 때)
  - **🔀 랜덤 순서** — 매 바퀴 순서를 섞습니다
- 각 문장의 **🔊** 로 그 문장만 듣거나, **🗑️** 로 삭제할 수 있습니다. **🗑️ 전체 삭제** 로 목록을 비웁니다.
- 속도(🐢/🐇)는 다음 문장부터 적용됩니다.

## 사용법 — 📖 읽기 (읽기 연습)

1. **▶️ 시작** 을 누르면 초중급(CEFR A2~B1) 수준의 지문이 만들어집니다. (약 400~500단어 = A4 1페이지 분량, 4~6문단)
2. 소리 내어 읽으며 연습하세요.
3. **🔊 전체 읽어주기** — 지문을 문단 순서대로 읽어줍니다. 현재 읽는 문단이 파랗게 강조되고 자동으로 따라 스크롤됩니다. 다시 누르면 정지.
4. **🇰🇷 번역 보기** — 각 문단 아래에 한글 번역을 켜고/끕니다.
5. **드래그 해석** — 모르는 단어나 문장을 마우스로 드래그하면:
   - 그 부분의 **한글 해석이 말풍선**으로 뜨고,
   - 동시에 **그 부분을 읽어줍니다.** (ESC 또는 빈 곳 클릭으로 닫기)
6. **글자 크기** 와 **속도(🐢/🐇)** 를 조절할 수 있습니다.
7. **🔄 새 지문** 으로 다른 지문을 받습니다.

## 사용법 — ✍️ 쓰기 (영작)

1. **🔄 새 문제** → 한국어 문장(5~12어절)이 제시됩니다.
2. 그 문장을 영어로 옮겨 적고 **Enter** 또는 **제출하고 채점** 을 누릅니다.
3. 결과:
   - **점수**와 **✍️ 내가 쓴 답**
   - **✅ 올바른 답** (🔊 로 발음 듣기 가능)
   - **💡 이렇게도 말할 수 있어요** — 다른 자연스러운 표현들 (각각 🔊 듣기)
   - **📝 피드백** — 어디가 어색했는지 한국어 설명

## 사용법 — 🗣️ 말하기 (스피킹)

1. **🔄 새 문제** → 한국어 문장이 제시됩니다.
2. **🎤 말하기** 를 누르고 그 문장을 영어로 말합니다. 인식된 내용이 **🎧 이렇게 들렸어요** 에 표시됩니다. (마음에 안 들면 **🎤 다시 말하기**)
3. **제출하고 채점** → 결과:
   - **점수**와 **🎧 내가 말한 것(인식 결과)**
   - **✅ 정답 문장** — 제출 즉시 **자동으로 읽어줍니다** (🔊 로 다시 듣기)
   - **📝 피드백** / **🔈 발음 팁**

> ⚠️ **발음 체크 방식**: 브라우저 음성인식이 받아적은 **텍스트**를 정답과 비교하는 방식입니다. 발음이 부정확하면 다르게 인식되므로 실용적인 지표가 되지만, 억양·강세를 음향적으로 정밀 측정하는 것은 아닙니다.

## 참고

- 마이크 음성 인식은 **Chrome / Edge** 에서 가장 잘 동작합니다. (Firefox·Safari는 제한적)
- 인터넷 연결이 필요합니다 (Claude API 호출).
- 더 빠르고 저렴한 모델을 쓰려면 `.env` 에 `CLAUDE_MODEL=claude-sonnet-5` 를 추가하세요.

## 파일 구조

```
english-conversation-app/
├── server.js          # Express 서버 + Claude API 호출 (API 키 보관)
├── package.json
├── .env.example       # 이 파일을 복사해 .env 로 만들고 키 입력
└── public/
    ├── index.html      # 회화 화면
    ├── app.js          # 회화: 음성 인식/출력 + 서버 통신
    ├── shadowing.html  # 쉐도잉 화면
    ├── shadowing.js    # 쉐도잉: 문장 재생 + 받아쓰기 채점
    ├── listen.html     # 듣기(흘려듣기) 화면
    ├── listen.js       # 듣기: 저장된 문장 무한 반복 재생
    ├── reading.html    # 읽기 연습 화면
    ├── reading.js      # 읽기: 지문 표시 + 전체 읽어주기 + 드래그 해석
    ├── writing.html    # 쓰기(영작) 화면
    ├── writing.js      # 쓰기: 한글 문제 + 영작 채점/대안 표현
    ├── speaking.html   # 말하기(스피킹) 화면
    ├── speaking.js     # 말하기: 한글 문제 + 음성인식 + 발음 체크
    ├── library.js      # 문장 저장/관리 (localStorage 공용)
    ├── speed.js        # 속도 조절 버튼 (공용)
    └── style.css       # 공통 디자인
```
